# مهرینه سالمند V4 — Kotlin + Android XML

نسخه بومی اندروید، مستقل از Flutter. امکانات: داشبورد، تماس، یادآوری، اعلام حال خطی، نمودار نمایشی ضربان، ویدئوهای آپارات درون برنامه، دستیار و اسلایدر تصویری، تنظیم اندازه نوشته با SeekBar، تم‌ها و میان‌بر برنامه‌ها.

## ویدئوهای آپارات
در بخش آموزش روی هر درس بزنید و لینک مستقیم و معتبر آن ویدئو را در قالب `https://www.aparat.com/v/VIDEO_ID` ثبت کنید. لینک‌ها برای هر درس جداگانه روی همان گوشی ذخیره می‌شوند. به دلیل نداشتن لینک‌های تأییدشده از طرف شما، هیچ URL جعلی قرار داده نشده است. پخش از طریق WebView فقط در بخش ویدئو انجام می‌شود و نیاز به اینترنت و اجازه embed ویدئو دارد.

## اتصال دو گوشی
این نسخه به اپ خانواده مستقل تقسیم شده است. همگام‌سازی واقعی بین دو گوشی هنوز فعال نیست؛ برای آن به سرویس ابری امن و تأیید اتصال توسط سالمند نیاز است. وضعیت سلامت و اعلان کمک را نباید بدون اتصال واقعی به‌عنوان داده زنده نشان داد.

## ساخت
ریشه پروژه را در یک مخزن GitHub جدا آپلود کنید و Actions را اجرا کنید. APK در Artifacts قرار می‌گیرد. بیلد در محیط فعلی آزمایش نشده است.
